my-cmp-youtube

my-cmp-youtube is a private tool used only by the owner of a YouTube channel to manage the settings of the videos on that channel (titles, hashtags and scheduled publish times) through the YouTube Data API.

It is not offered to anyone else. It does not upload, download or delete videos, and it does not share any data with third parties.

This tool uses YouTube API Services.

日本語

my-cmp-youtube は、ある YouTube チャンネルの持ち主が、自分の動画の設定(タイトル・ハッシュタグ・公開予約)を YouTube Data API で整えるためだけに使う個人用の道具です。他の人には提供していません。 動画のアップロード・ダウンロード・削除はせず、データを第三者に渡しません。
